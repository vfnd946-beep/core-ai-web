# CORE AI Web — Phase 1

واجهة عربية متجاوبة لمشروع CORE AI، تشمل مساحة عمل، محرر HTML، معاينة حية داخل iframe مع sandbox، سجل تشغيل بسيط، وتنزيل index.html.

## تشغيل محلي
يمكن فتح `index.html` مباشرة في المتصفح. لا تحتاج الواجهة في هذه المرحلة إلى خادم أو مفاتيح API.

## حدود المرحلة الأولى
- المحادثة واجهة تجريبية فقط وليست متصلة بنموذج AI.
- البحث الخارجي وربط API سيأتيان في المرحلة الثانية.
- المحرر يدعم HTML كنموذج أولي، والمعاينة ليست بيئة تشغيل عامة آمنة للكود غير الموثوق.
- لا يوجد رابط استضافة عام بعد؛ يتطلب ذلك رفع الملفات إلى خدمة استضافة. هذا المجلد جاهز للرفع كصفحة ثابتة إلى GitHub Pages أو Netlify أو Cloudflare Pages.
